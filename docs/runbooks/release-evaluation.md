The loader enforces exact split counts, unique IDs/questions, family separation, bounded files, source-reference shape and basic label consistency. `evaluation.metrics.release_support_recall(dataset, frozen_folder, reviewed_spans, batch)` scores reviewed fact support without provider calls. The batch contains `dataset_sha256`, `sources_manifest_sha256` and `cases` mapping every dataset ID to its `execute_http_turn` result. The scorer rejects pending labels/span review and missing/mismatched cases. It checks the first ten captured pipeline hits against exact normalized source text/offsets; private uploads without URLs and other sources do not count as frozen support. Alternative spans and duplicate hits count each required fact once. Failed executions remain in the denominator; boundary cases with no factual supports have a null value and zero denominator. Reported micro averages include explicit matched/required-fact counts per case, per split and overall. The report hashes dataset, source manifest, reviewed span choices and captures. It does not measure answer correctness, replace human review or authorize acceptance.
